# Projeto_Itinerario_2
Projeto de Itinerário do 4º Semestre.


Aplicação Web voltada para divulgação da Igreja Nova Geração, bem como informar sobre Cultos, Eventos e Ministérios.
Conta com um sistema para gerenciamento interno de integrantes em ministérios e métricas sobre eventos, cultos e batismos.
